# BF550 · Unit 5 labs

The lab notebook for unit 5, one part for each of the unit's class meetings.
You work through it during lab time, with instructors and TAs in the room, and
carry on in the same notebook at the next meeting if you do not finish a part.
Nothing here is submitted and nothing here is graded.

| Lab | Notebook | Meetings |
|---|---|---|
| Unit 5 lab · Dictionaries, `and`, and sums of logs | `unit-05.ipynb` | Mon Oct 5 · Wed Oct 7 · Fri Oct 9 |

## Run them

Open a notebook in VS Code and pick the `bf550` kernel, the environment your problem sets
ship. There is no second environment.

Each lab carries its own self-checks. They report and never grade: ⬜ not attempted, ❌ not
passing yet with a hint, ✅ passing. Run a check as often as you like. It only reads your work.

## Break them

These notebooks are for changing. Move a line, predict what happens, run it, find out whether
you were right. Every cell is editable on purpose. If you wreck one beyond repair,
`git checkout <notebook>` puts it back the way it shipped. Commit and push whenever you like;
this repository is yours.

## The next unit's labs

Each unit has its own repository. At a unit's first meeting you run

```bash
gh student accept bu-bioinfo-classrooms bf550-fall-2026 bf550-unitNN-labs
```

with that unit's number in place of `NN`, then clone what it creates, exactly as you did
for this one.
